# Biblioteca de Anuar Maximiliano

Página: https://anuar-science.github.io/anuar-maximiliano/

## Subir un artículo
1. Abrir la página y pulsar el botón rojo **Subir artículo**.
2. Llenar título, tema, fecha, qué leyó y el texto.
3. Pulsar **Publicar**: GitHub se abre con el archivo ya escrito en `articulos/`.
4. Pulsar **Commit changes** (dos veces). El artículo aparece en uno o dos minutos.

## Subir una imagen para un artículo
1. Ir a https://github.com/anuar-science/anuar-maximiliano/upload/main/articulos/img y arrastrar la foto.
2. En el texto del artículo escribir `![descripción](img/nombre-de-la-foto.jpg)`.

## Cambiar el fondo
El fondo es una ilustración propia con los emblemas de los Vengadores. Para usar una foto, subirla como `img/fondo.jpg`; la página la muestra sola.
